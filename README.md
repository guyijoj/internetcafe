План действий:
1 - при нажатии на кнопки веб-сайт попросит способ оплаты

    - Если оплата прошла успешна выводит сообщении о успешной оплаты - Иначе выводит ошибка

2 - После успешной оплаты показывает статус заказа и информации о заказе

3 - Данные отправляются к ресторану

4 - Блюда приготвляваются и сообщают клиенту
